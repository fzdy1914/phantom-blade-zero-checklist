# 影之刃零 · 一周目全成就路线簿

中文静态检查清单网站，按剧情顺序梳理 9 个区域、Steam 66 项成就、可错过节点、支线与收集品。纯 HTML、CSS、JavaScript，无需构建步骤。

## GitHub Pages 部署

1. 将本目录内容推送到 GitHub 仓库的 `main` 分支。
2. 在仓库的 **Settings → Pages → Build and deployment** 中，将发布来源设为 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`。
3. 保存后，GitHub Pages 会自动发布；后续推送到 `main` 也会自动更新。
4. 网页地址为 `https://<用户名>.github.io/<仓库名>/`。

`.nojekyll` 文件确保 GitHub Pages 直接提供静态文件，不依赖构建器。

## 进度保存与备份

- 勾选和计数保存在当前浏览器的 `localStorage`，不会上传到 GitHub 或服务器。
- 同一浏览器和网站地址会保留进度；换设备、换浏览器或清理浏览器数据前，请用页面右上角的 **导出进度** 下载 JSON。
- **导入进度**会合并勾选项，并在计数上采用较大值，避免较旧的备份覆盖较新的本机进度。
- 浏览器隐私模式可能在关闭窗口后清理本地数据；JSON 备份可用于恢复。

## 页面内容

- 错过节点：区域头目与关键过场前的检查项，并标出资料有分歧的保守路线。
- 分区域路线：每区成就、支线、地图核对数、关键物品与外部逐点地图链接。
- 全局收集目标：成就门槛、五条红绳、四面具、五根龙柱、五场菩提试炼、快手张宝物与真结局紫色任务。
- 全成就清单：66 项 Steam 成就的中文名、条件、筛选、搜索与完成状态。

## 资料口径

游戏并非传统的明文章节结构，本表按攻略常用的 9 个剧情区域排列；“戏梦山庄”在庞镇的地图进度中单独列出。计数以各区域攻略页为核对参考，指南之间存在少量计数、名称和截止时间分歧；游戏任务日志与实际版本状态优先。清单按 Steam 66 项整理，PS5 使用不同的 36 个奖杯列表。

页面名称与游戏内专有名词均以中文显示；Steam 与相关指南名称保留其品牌原文。
