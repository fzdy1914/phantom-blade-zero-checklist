# 影之刃零 · 一周目全成就路线簿

中文静态网站，按主线顺序整理 Steam 66 项成就所需步骤。错过截止点直接放在对应区域路线中；清单只列成就必做项和明示数量，不要求区域 100% 清图。

## GitHub Pages

1. 将本目录推送到 GitHub 仓库的 `main` 分支。
2. 在仓库 **Settings → Pages → Build and deployment** 选择 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`。
3. GitHub Pages 会在推送后自动发布更新。

## 进度保存与备份

- 勾选和计数保存在当前浏览器的 `localStorage`，不会上传到服务器。
- 右上角 **导出进度** 下载 JSON 备份；**导入进度**可合并恢复，计数取较大值。
- 清理浏览器数据或换设备前，请先导出备份。

## 内容口径

- 成就分为“流程推进成就”和“需要主动完成的成就”。
- 区域路线按故事顺序列出成就必做任务、步骤、数量门槛和错过节点。
- 数量目标仅包含成就门槛，例如 10 朵完整记忆之花、30 件饰品、五根龙柱及五场菩提试炼。
- 游戏没有传统明文章节，本页按 9 个剧情区域整理；成就按 Steam 66 项整理。

## 文件

- `index.html`：网站结构与说明
- `styles.css`：桌面与移动版式
- `app.js`：成就和路线数据、本机保存、JSON 导入导出
- `.nojekyll`：GitHub Pages 静态站点标记
